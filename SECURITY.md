# Security Policy

## Supported Versions

Only the latest published release of AALyrics is currently supported with security updates.

During pre-release development, this includes the latest published alpha, beta, or release candidate.

Older releases may not receive security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues or Discussions.

Instead, use GitHub's private vulnerability reporting feature for this repository.

When reporting a vulnerability, please include, where possible:

- A description of the vulnerability
- Steps to reproduce it
- The affected AALyrics version
- Relevant Android version and device information
- The potential impact

There is currently no fixed response-time SLA. Reports will be reviewed as availability permits.

If a vulnerability is confirmed, remediation and disclosure will be coordinated through GitHub's private security reporting workflow where appropriate.

Regular bugs that do not involve a security issue should be reported through GitHub Issues.
