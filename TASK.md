# Gradle Wrapper Task

This branch fixes local/IDE Gradle reproducibility without changing the intentional Android/Kotlin toolchain versions.

## Scope

- [x] Create a dedicated `build/add-gradle-wrapper` branch from `main`.
- [x] Generate a fresh Gradle Wrapper for Gradle 9.6.0 using the official Gradle wrapper task.
- [x] Keep AGP 9.4.0, Kotlin 2.4.20, and compile/target SDK 36 unchanged.
- [x] Update CI to use `./gradlew` rather than a separately provisioned `gradle` executable.
- [x] Remove the temporary wrapper-bootstrap workflow after generation.
- [x] Verify the wrapper files and executable mode are committed correctly.
- [ ] Open a focused PR to `main`.
- [ ] Run CI and Codex review.
- [x] Stop before merge for explicit approval.

## Verification evidence

- `gradle/wrapper/gradle-wrapper.properties` pins `gradle-9.6.0-bin.zip`.
- `gradle/wrapper/gradle-wrapper.jar` was generated by the official Gradle 9.6.0 wrapper task.
- `gradlew` is committed with executable mode `100755`; `gradlew.bat` is committed for Windows.
- The temporary bootstrap workflow was removed after generation and is not part of the final branch contents.
- CI now invokes `./gradlew :app:assembleDebug` and `./gradlew test`, so local/IDE and CI builds share the checked-in Gradle runtime contract.

## Notes

The wrapper is generated for AALyrics itself; it is not copied from the previous Auto Lyrics fork. The previous fork currently targets Gradle 8.4 and is not the source for these files.

No AGP, Kotlin, SDK, or application behavior changes are included in this branch.
